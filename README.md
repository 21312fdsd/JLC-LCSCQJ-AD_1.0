## 功能

- 网页原版下载：输出 STEP、SchDoc、PcbDoc。
- 本地转换模式：输出 STEP、SchLib、PcbLib。
- 支持批量料号、扫码登录、账号密码登录和 Windows 凭据保存。
- 自动检查下载文件完整性，失败时自动重试。

## 本次更新
